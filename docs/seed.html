Заполнение каталога тестовыми товарами

Эта страница добавляет 50 товаров из data/seed-products.js (включая категорию «Готовые ПК») в коллекцию products. Firestore Security Rules разрешают запись в products только пользователю с ролью admin, поэтому сначала войдите под аккаунтом администратора.

Как сделать первого администратора: зарегистрируйтесь на сайте как обычно, затем в Firebase Console → Firestore Database → коллекция users → найдите свой документ (uid) и вручную измените поле role с "user" на "admin". После этого войдите на сайте этим аккаунтом и вернитесь на эту страницу.
